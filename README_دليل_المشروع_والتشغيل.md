# مشروع التخرج: نظام "سند" (TechCare) الذكي لإدارة الأجهزة والصيانة التقنية
> **معك دائماً.. نحو بيئة تقنية أكثر استقراراً**

## 📁 محتويات ملف المشروع الكامل (Project Structure)

1. **`frontend/` (واجهة الموقع الكاملة مع الأيقونات والصور والشعار الرسمي)**
   - `index.html` : الصفحة الرئيسية التي تضم جميع الواجهات الـ 10 للنظام.
   - `assets/css/style.css` : ملف التنسيقات والألوان الرسمية المتناسقة مع عرض المشروع (`#1e3a5f` الكحلي الملكي + `#f6f7f9`).
   - `assets/js/app.js` : البرمجة التفاعلية الكاملة (إدارة الأجهزة، البلاغات، الصيانة، توليد رمز QR، الرسوم البيانية، وتبديل الصلاحيات).
   - `assets/images/` : الشعار الرسمي لـ **سند** بخلفية شفافة (`sanad_logo_full.png` و `sanad_logo_icon.png`) وصور الواجهات.
   - `assets/icons/` : أيقونات SVG مخصصة للأجهزة والأعطال والصيانة ورموز QR.

2. **`Sanad_Standalone_AllInOne.html`**
   - نسخة مدمجة بالكامل في ملف واحد (تعمل فوراً بمجرد النقر المزدوج عليها في أي جهاز بدون الحاجة لإعداد خادم).

3. **`database_mysql/sanad_mysql_schema.sql` (قاعدة البيانات MySQL)**
   - ملف SQL متكامل جاهز للاستيراد في **MySQL Workbench** أو **XAMPP (phpMyAdmin)**.
   - ينشئ قاعدة البيانات `sanad_techcare_db` والجداول الأربعة المعتمدة في العرض:
     1. جدول المستخدمين (`Users`)
     2. جدول الأجهزة (`Devices`)
     3. جدول الأعطال (`Faults`)
     4. جدول الصيانة (`Maintenance`)
   - يحتوي على العلاقات (`Foreign Keys`) والبيانات الأولية التجريبية باللغة العربية.

4. **`backend_django/` و `backend_flask/` (البرمجة الخلفية بلغة Python)**
   - `backend_django/core_app/models.py` و `views.py` : نماذج الجداول والـ Views باستخدام إطار **Django** كما ورد في خطة المشروع.
   - `backend_flask/app.py` : خادم Python خفيف لتشغيل الموقع محلياً عبر العنوان `http://127.0.0.1:5000`.

---

## 🚀 طريقة التشغيل السريعة يوم المناقشة

### الطريقة الأولى (الأسرع — بدون أي إعدادات):
- افتح المجلد `frontend` واضغط مرتين على ملف `index.html` (أو افتح ملف `Sanad_Standalone_AllInOne.html`).
- سيعمل الموقع مباشرة بكافة واجهاته الـ 10 والرسوم البيانية ورموز QR.

### الطريقة الثانية (عبر خادم Python):
```bash
pip install -r requirements.txt
python backend_flask/app.py
```
ثم افتح المتصفح على: `http://127.0.0.1:5000`

### الطريقة الثالثة (استيراد قاعدة البيانات في MySQL Workbench أو XAMPP):
1. افتح **MySQL Workbench** أو **phpMyAdmin**.
2. اختر **Import** وحدد الملف `database_mysql/sanad_mysql_schema.sql`.
3. اضغط **Execute** لإنشاء الجداول الأربعة وملئها بالبيانات.
